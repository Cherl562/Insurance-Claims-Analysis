# Insurance-Claims-Analysis
This project is an end-to-end data analysis solution built to explore and visualize insurance claims data. The goal is to identify trends in claim types, approval rates, claim amounts, and operational insights that can help improve decision-making and efficiency. Using data transformation, modeling, and visualization techniques, the project turns raw claims data into an interactive dashboard that highlights key business metrics such as approval rate, most frequent claim types, and total claim distributions. This project demonstrates skills in data cleaning, DAX calculations, data modeling, and dashboard development.

Tools & Technologies:
* Power BI (Data Visualization & Dashboarding)
* DAX (Calculated Measures & KPIs)
* Power Query (Data Cleaning & Transformation)
* Excel / CSV (Data Source)

Key Features / Insights:
📈 Approval Rate Analysis using calculated DAX measures
📊 Most Frequent Claim Types breakdown
💰 Total Claim Amount analysis by category
🔍 Interactive filters (claim type, status, date, etc.)
📉 Trends in claims over time (if applicable)

Key Learnings:
Building relationships between multiple data tables
Writing DAX measures for KPIs (Approval Rate, Counts, etc.)
Cleaning and merging datasets for accurate reporting
Designing a recruiter-friendly dashboard layout
Translating raw data into actionable insights
